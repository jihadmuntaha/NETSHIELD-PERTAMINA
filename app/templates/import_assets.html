Panduan Format File Assets

NetShield mendukung berbagai format standar data pemantauan jaringan:

Google Earth (.KMZ / .KML)

Mengekstrak tag <Placemark>, koordinat spasial, serta IPv4 & Zona dari deskripsi placemark.

Spreadsheet (.CSV / .XLSX)

Kolom header otomatis terdeteksi: Name, IP, Area/Zona, dan Type.

GeoJSON / JSON (.json / .geojson)

Mendukung ekspor topology GeoJSON FeatureCollection atau array JSON inventaris perangkat.

Text List (.TXT)

Daftar baris alamat IP & nama perangkat sederhana. Sistem mengekstrak IPv4 otomatis.

Autokomposisi NetShield:

Jika IP atau Zona tidak tercantum dalam file, NetShield mengalokasikan Subnet IP & Zona area secara cerdas.
