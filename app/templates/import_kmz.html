Panduan Format Google Earth

File .kmz adalah arsip terkompresi ZIP yang berisi dokumentasi spasial KML dari Google Earth.

Atribut XML yang Diekstrak:
  • <Placemark>: Objek node utama.
  • <name>: Nama unik perangkat.
  • <coordinates>: Latitude, Longitude, Elevation.
  • <description>: Metadata IP/Zona jika ada.
Aturan Auto-Assign NetShield:
  • Zona Area: Otomatis dicocokkan berdasarkan kata kunci nama ("Zona 1", "Tank Farm", "Filling", "Server"). Fallback ke Zona 2.
  • IPv4 Address: Mengekstrak pola IPv4 dari deskripsi. Jika kosong, mengalokasikan subnet dummy FT Pengapon (10.4.x.x).
  • Tipe Perangkat: Mengidentifikasi keyword Router, Switch, atau CCTV.
